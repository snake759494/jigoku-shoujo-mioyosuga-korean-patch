# 이미지 한글화 작업 공통 규칙 (에이전트용)

- 원본: extract/img_orig/<key>.png (key = fileid_path_pic, 예 603_0_0, 500__0, 751_1-3_0). 조사표: translation/img_survey.tsv (path 열의 '.'은 key에서 '-').
- 결과: translation/img/out/<key>.png — **원본과 같은 크기의 RGBA PNG**. 빌드(tools/build.py)가 자동으로 TIM2에 다시 씁니다(8bpp 이미지는 256색으로 재양자화됨).
- 도구: tools/imgdraw.py (font(), orig(), save(), inpaint(), mask_where(), text_layer(), over(), fit_size(), sheet()). 필요하면 담당 스펙 파일 안에서 자체 함수를 써도 되지만 imgdraw.py는 수정하지 말 것.
- 스펙 스크립트: tools/img_specs/<담당이름>.py 하나에 담당 이미지 전부의 생성 코드를 두고, `python tools/img_specs/<담당이름>.py` 로 다시 만들 수 있게 할 것.
- 폰트: 기본은 서울한강체(SeoulHangang L/M/B/EB). 원본이 붓글씨·명조면 서울한강 B/EB, 둥근 고딕 UI(예: 667 미니극장 제목)면 NanumSquareNeo 사용 가능. 굵기·크기·색·테두리·광채·그림자는 원본과 비슷하게.
- 방법: 원본 글자 픽셀을 마스크로 잡아(안티앨리어싱 가장자리까지 grow) inpaint로 지우거나, 단색/투명 배경이면 그 색으로 채운 뒤 한글을 그림. 상태 세트(일반/선택/비활성 등)는 같은 배치·크기로 통일.
- 반드시 sheet()로 원본/결과 비교 이미지를 만들어 눈으로 확인하고, 잔상(일본어 흔적), 넘침, 잘림이 없을 때까지 반복할 것. 미리보기 PNG는 scratchpad 하위 담당 폴더에만 저장.
- 인물 표기: 미카게 유즈키, 칸바야시 아스카, 리쿠도 루이, 쿠사오 하루토, 시노사키 아유미, 이시모토 렌, 엔마 아이, 소네 안나, 후와 류도, 야마와로, 키쿠리, 키비츠 타카야스, 카사마 미사키, 마츠카타 토모히코/노부히코/야요이코/미야, 쿠사오 마사하루, 시노사키 효마, 무라카미 아키오, 이치모쿠렌, 호네온나, 와뉴도. 媛馬村=히메우마 마을. 地獄通信=지옥통신. (translation/glossary.tsv 참고)
- 담당 외 파일은 수정 금지. 기계번역 금지(짧은 UI 문구도 직접 정함).
- 마지막 보고(한국어): 처리한 key 수, 처리하지 못했거나 품질이 미흡한 key와 이유.
