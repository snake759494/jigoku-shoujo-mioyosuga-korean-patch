## PTDALL.PID
- `u32 아카이브 수(12)`, `u32 항목 수[12]`, `0x34`부터 이름 16바이트×12.
- `0xF4`부터 항목 표가 아카이브 순서대로 이어진다. 항목 = `(u32 시작 섹터, u32 크기)`이고, 섹터는 해당 PTD 파일 안에서의 2,048바이트 단위다.
- 게임은 PTD 파일을 파일 시스템 이름으로 찾는다(실행파일에 LBA 고정값 없음). 그래서 PTD 파일이 커지면 ISO 끝으로 옮기고 디렉터리 레코드만 고치면 된다 (`tools/isofs.py`).

## 스크립트 (PTD002)
- 헤더 `u16[8]` = `0x10, 코드 시작, 문자열표 시작, 본문 시작, 0x1FF, 코드 길이, 문자열 수, 본문 길이`.
- 문자열표는 본문 기준 `u16` 오프셋이고, 본문은 NUL로 끝나는 SJIS 문자열이다. 페이지 안 줄바꿈은 `\n`이고 페이지 끝에도 `\n`이 붙는다.
- 바이트코드는 문자열을 번호로만 참조한다. 그래서 문자열표와 본문만 다시 쓰면 된다(파일당 64KB 한도, 실제 최대 약 17KB).
- 대사 표시 명령은 `61 00 (28|38)+상위비트 하위바이트`이고, 음성 명령 `61 44 <캐릭터>`의 캐릭터 번호가 실행파일 이름 목록(1부터)과 대응한다. 이것으로 번역 문맥용 화자표 `translation/speakers.json`을 만들었다.

## 글꼴 (PTD003, T2FP)
- `'T2FP'`, 헤더 0x20, 글리프 24×24, 코드표 시작 0x20, CLUT(16색) 오프셋, 글리프 오프셋.
- 코드표는 정렬된 `u16` 문자 코드 7,181개다(SJIS는 빅엔디언 값, 0x100 미만은 1바이트 문자). 글리프는 4bpp이고 왼쪽 픽셀이 하위 니블이다. 원본은 0/15 두 값만 쓴다.
- 한글 2,350자는 한자 코드 `0x889F`부터 코드표 순서대로 1:1 대응한다 (`translation/charmap.json`). 가나·기호·ASCII 글리프는 그대로 둔다.
- 1바이트 문자(ASCII 공백·문장부호)는 12px, 2바이트 문자는 24px 간격으로 그린다. 그래서 대사창 한 줄은 34칸(한글 17자)이다.

## 실행파일 문자열
- `.rodata`/`.sdata`의 SJIS 문자열이다. 참조는 데이터 포인터(`u32 vaddr`, vaddr = 파일 오프셋 + 0xFF000)이거나 `lui/addiu` 쌍이다.
- 원래 칸에 들어가면 제자리에 쓰고, 넘치면 번역 후 남은 다른 칸의 여유 공간으로 옮겨 참조를 고친다. `lui/addiu` 쌍은 같은 레지스터가 중간에 다시 로드되지 않을 때만 인정한다(오탐 방지).
- 대화창 이름 칸은 문자열이 아니라 이미지다(아래 700번).

## 이미지 (PTD000)
- 항목은 TIM2이거나 `u32 n, u32 오프셋[n+1]` 형태로 중첩된 컨테이너다 (`tools/tim2.py walk()`).
- 형식은 32bpp(대부분), 24bpp(배경), 8bpp+32비트 CLUT(CSM1 스위즐)이다. 크기와 형식을 유지해 제자리에 다시 쓰므로 항목 크기가 바뀌지 않는다.
- 8bpp 이미지는 **CLUT 0번이 투명색(키 색)**이다. 다시 양자화할 때 원래 0번 색을 0번에 고정하고, 그 색 픽셀을 모두 0번에 매핑한다.
- 700번: 짝수 = 이름판 글자(180×31), 홀수 = 글자 수만큼 칸이 그려진 타일(8bpp, 초록 키), 50~59번 = 꽃무늬 타일(자홍 키). 게임은 타일 위에 이름판을 겹쳐 그리고, 칸 위치는 x = 0/35/71/107/143 (폭 약 33)이다.

## 동영상 (PSS)
- MPEG-PS이고, 비디오는 720×480 29.97fps(상위 필드 먼저, GOP 15, VBV 1,835,008)다.
- 음성은 private stream 1(서브 ID 0xFF)의 `SShd`/`SSbd` 16비트 PCM 48kHz 스테레오다.
- 자막이 걸린 GOP 구간만 디코드→합성→닫힌 GOP로 재인코딩한다. 원본 구간 바이트 이하가 되는 가장 고운 q를 고르고, 남는 부분은 0으로 채워(시작 코드 앞 0 채움) 비디오 ES 길이를 원본과 같게 맞춘 뒤 PES 페이로드 자리에 되돌려 쓴다. 팩 구조·음성·파일 크기는 원본 그대로다 (`tools/pss.py`, `tools/movie_sub.py`).
- 음성 받아쓰기는 faster-whisper large-v3로 했고, 번역은 직접 했다 (`movie/subs/*.tsv`).
