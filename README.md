# 지옥소녀 미오요스가 PS2 한글패치

PS2 일본판 **地獄少女 みおよすが (SLPM-55213)**용 비공식 한국어 패치입니다. 대사 전부, 실행파일 안의 시스템·도움말 문자열, 메뉴·이름판·장 카드 등 이미지 글자를 한국어로 바꾸고, 음성만 있던 동영상 2편에 한글 자막을 넣었습니다. 현재 배포판은 **v1.0 (2026-09-26)**입니다.

## 게임 소개 및 대상 버전

「地獄少女 みおよすが」는 컴파일 하트가 2009년 PS2로 낸 애니메이션 「지옥소녀」 원작 어드벤처 게임입니다. 산골 마을 히메우마에서 벌어지는 지옥 보내기 사건을 유즈키·하루토·아유미·아스카 등 여러 주인공의 시점으로 따라가며, 선택지에 따라 결말이 달라집니다.

이 패치는 **PS2 일본판 SLPM-55213** 에만 적용합니다. 파일 이름보다 아래 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows 에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Jigoku Shoujo Mioyosuga (Japan).iso'
```

위 표와 다르면 적용을 중단하고 원본 상태를 확인하세요. CHD·CSO·BIN/CUE 를 ISO 처럼 이름만 바꿔서는 사용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Jigoku_Shoujo_Mioyosuga_PS2_KO_v1.0.xdelta` 를 받습니다.
2. xdelta3 패치를 지원하는 도구의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 ISO 를 선택합니다.
4. **Output File** 에 새 파일명(예: `Jigoku Shoujo Mioyosuga (Korean v1.0).iso`)을 지정합니다.
5. 적용 후 결과 ISO 의 SHA-256 을 위 표와 비교합니다.

xdelta 는 호환성을 위해 2차 압축과 파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Jigoku Shoujo Mioyosuga (Japan).iso' '.\Jigoku_Shoujo_Mioyosuga_PS2_KO_v1.0.xdelta' '.\Jigoku Shoujo Mioyosuga (Korean v1.0).iso'
```

해시를 자동 검사하는 도구도 있습니다(Python 3 + xdelta3 필요, 기존 출력 파일은 덮어쓰지 않음).

```powershell
python tools/apply_release.py --xdelta '.\xdelta3.exe' --source '.\원본.iso' --patch '.\Jigoku_Shoujo_Mioyosuga_PS2_KO_v1.0.xdelta' --output '.\Korean.iso'
```

### PCSX2 에서 실행

게임을 완전히 종료한 뒤 새 ISO 를 여세요. 원본판의 세이브 스테이트는 불러오지 마세요(실행파일 내용이 다름). 이어 하기는 게임 안 메모리카드 저장을 쓰세요.

## 작업 내용과 범위

| 구분 | 작업량 및 내용 |
| --- | --- |
| 대사 | 스크립트 78개의 문자열 11,101개(고유 7,459개, 원문 약 28.6만 자) 전부. 대사창 한 줄 전각 17자·4줄 기준으로 직접 줄바꿈 |
| 실행파일 문자열 | 239개(메모리카드·시스템 메시지, 조작 방법 도움말, 인물 이름). 넘치는 10개는 여유 공간으로 옮기고 포인터 수정 |
| 글꼴 | 24×24 게임 글꼴 2종(본문·굵은 글꼴)의 한자 자리에 한글 2,350자(KS X 1001). 서울한강체 B/EB를 원본 붓글씨 글꼴의 획 두께에 맞춰 흑백 글리프로 변환 |
| 이미지 | TIM2 이미지 371장(타이틀·인게임 메뉴, 옵션, 갤러리, 캐릭터 선택 양초, 대화창 이름판, 장 카드, 지옥통신 화면, 이름 입력 애니메이션 124프레임 등) |
| 대화창 이름 칸 | 이름 글자 수만큼 칸(타일) 이미지를 다시 그림. 최대 5칸이라 6자 이상인 이름은 이름만 표시(예: 토모히코) |
| 동영상 자막 | 음성이 있는 동영상 2편(MOVIE_02 내레이션, MOVIE_04 엔마 아이 대사)에 대사와 같은 서울한강 B·같은 크기, 흰 글자+검은 테두리 자막. 자막 구간만 재인코딩해 파일 크기는 원본과 같음 |

번역하지 않은 것: 타이틀 로고, 오프닝 노래 가사(MOVIE_01), 아이템 아이콘 속 아주 작은 글자, 배경 그림 속 간판 글자.

## 알려진 한계

- 대화창 이름 칸이 최대 5칸이라 긴 이름은 성을 빼고 표시합니다.
- 일부 메뉴 이미지는 원래 글자를 지운 자리의 무늬가 약간 번져 보입니다. 이미지 속 글자는 서울한강체로 다시 그려 원본 붓글씨보다 반듯합니다.
- 크레딧의 일부 인명(真下好, 福谷大 등)은 읽는 법을 확인하지 못해 추정으로 적었습니다.
- 에뮬레이터(PCSX2)에서 제작자가 주요 화면을 확인했으나 모든 시나리오와 결말을 끝까지 검증하지는 못했습니다. 문제를 발견하면 이슈로 알려 주세요.
